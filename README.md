# Sanwo for Laravel

Sanwo payment SDK for Laravel — one interface for every payment provider.

> **Full documentation at [docs.sanwo.dev](https://docs.sanwo.dev/sdks/laravel/)** — guides, examples, and API reference for every SDK and provider.

## Install

```bash
composer require sanwohq/laravel
```
